## Fixed

- **To the front when reused**: a Dirq window that is already open and gets a new document (`--reuse`, as CodeDeck opens it) now comes to the front. Under Cinnamon and other X11 desktops it used to only light up in the taskbar.

Install: `sudo apt install dirq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
