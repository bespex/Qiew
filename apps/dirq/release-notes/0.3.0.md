## What's new

- **Syntax colours** for many languages (Rust, TypeScript, Java, XML, Python, Go, SQL, YAML, Dockerfile, Gradle, Protobuf, Nginx and more), in all four colour schemes and in the HTML export. The old and the new side are coloured apart, so a comment that runs across hunks stays a comment; changed words stay marked on top.
- **Generated files fold themselves**: lock files, minified bundles, snapshots, source maps and `dist/` start folded with a hint, and still count in the totals.
- **File list**: filter by path, filter by new / changed / deleted / renamed, sort by patch order, size or status, and an outline of the functions named in the `@@` lines.
- **Keyboard**: Alt+↓ / Alt+↑ next and previous file, Alt+← / Alt+→ back and forward along your jumps, Ctrl+Shift+O shows or hides the file list, `?` lists all keys (also in the menu).
- **Live review**: while a patch changes, the view keeps its place (by the hunk you are reading), folded files and the filter stay. What is new flashes and keeps a bar at the left, with a dot in the file list and marks on a ruler beside the scroll bar.
- **`--id <text>`**: a program that hands Dirq patches through standard input (such as CodeDeck) can say which document a call brings; the same text means a new version of the same document. Put it after the `-`.

Install: `sudo apt install dirq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
