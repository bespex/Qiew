## What's new

- **Comments for the assistant** (`--annotate`): a program that starts Dirq, such as CodeDeck, can let you comment on single lines – context, added and removed ones. A "+" in the margin or Ctrl+Alt+M opens a card under the line; Ctrl+Enter sends the comment to that program, which hands it to the AI with your next prompt. Comments stay at their line while the patch changes. Without the option Dirq is unchanged. Without anything to send to, the comments stay in the window and can be copied as a Markdown list.
- **More lines around a change** (`--repo <path>`): between the hunks, "20 more", "All" and "Whole file" read the missing lines from the Git repository, read-only, numbered on both sides and in colour. Files the repository's `.gitattributes` mark as generated fold themselves.
- **One file alone**: a button in the toolbar shows one file at a time under a compact header; `--file <path>` starts with that file. CodeDeck's Changes open a file this way on a double click.
- **Toolbar**: two navigations side by side, changes (± ↑ 2/5 ↓) and files (‹ 2/7 ›), each with where you are; the centre names the file shown.
- **Keys**: up and down within, left and right across. Alt+↓ / Alt+↑ jump from change to change (F7 / Shift+F7 still work), Alt+→ / Alt+← from file to file. Going back along your jumps moves to Alt+Shift+← / Alt+Shift+→ and the mouse's back and forward buttons. F7 also works now when the patch fits the window or you are at its end.
- **File list**: a wider side panel (300 pixels) whose width you drag at its edge (200 to 400); it lists the files only (the function names under each file are gone) and folds away.
- **Esc closes the window** when nothing else (the search, a menu, a card) takes it. While comments have reached nobody, the first Esc shows them and a second one closes anyway.

A Dirq window that was opened before the update and is still open takes new documents but ignores the new options; close it once.

Install: `sudo apt install dirq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
