## What's new

- **A button of its own for comments** (`--annotate`): Dirq's comments go to the program that started it (CodeDeck), not into the patch, so the margin button is no longer a "+" but a speech bubble with an arrow. Its tooltip says whether anything receives the comment.
- **Clearer cards**: the input card says where the comment goes and where it does not, and a sent comment carries the badge "sent to CodeDeck".

A Dirq window that was opened before the update and is still open takes new documents but ignores the new options; close it once.

Install: `sudo apt install dirq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
