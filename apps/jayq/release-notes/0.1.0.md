## What's new

First release. JSON as a coloured, foldable tree, as written if it is not valid; a split view runs a **jq filter** over it.

- Values stay exactly as written: number spelling, large integers, string escapes, key order, duplicate keys. Several values in a row (JSON Lines, jq output) are supported.
- The filter runs in jaq, built into the program, in a worker process of its own that ends after 10 seconds or with the next run.
