## What's new

- **Comment lines before the table**: lines starting with `#` above the table (as some exports write them) are set aside instead of becoming rows, and the status bar counts them. A `#` line that splits like the table itself (`#;Name;Value`) stays data.
- **Surer delimiter detection**: comma, semicolon, tab or pipe is now told from the first records as the parser reads them, so quotes and line breaks inside cells no longer mislead it.

Install: `sudo apt install cusq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
