## What's new

First release. Runs a `.tsx` or `.jsx` file as it is: oxc translates it in memory, the component runs in a frame of its own origin (`tusq://`) with React, Tailwind, lucide-react and recharts built in. The window takes the width the component is made for, the toolbar the colour of its page.

- **About box**: name and how to say it, purpose, file endings, default viewer and links. The question about becoming the default viewer now names the app it would replace.
