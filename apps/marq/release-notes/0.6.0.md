## What's new

- **Comments on blocks**: comments live in the Markdown file as HTML comments before a block (`<!-- @ai: … -->`, `@me`, `@you`; done as `@ai#erledigt`). Marq always shows them as small marks in the left margin, in the colour of their type; pointing at a mark shows the text. Nothing is written without being asked.
- **Writing comments with `--annotate`**: started with `--annotate`, a "+" in the margin of a block (or Ctrl+Alt+M) opens a card; choose `@ai`, `@me` or `@you`, Ctrl+Enter saves. A comment can be ticked off, changed and deleted from its card, and F7 jumps from comment to comment. What you typed survives a live reload.
- **Safe writing**: `--annotate` holds for the file of that call only; a file handed over again without it, opened by a link or dropped stays read-only. Marq writes only if the file is still what the change was made from, atomically and with its permissions, and nothing if it is not certain where the comment belongs.
- **A new icon**: two asterisks as eyes over a smile, Markdown's own characters.
- **Updates** now look at the new address of the bespex organisation.
- Fixed: in a tight list the comment marks sit beside the item's text (WebKit moved them below it), and the "+" steps aside while you point at the marks.
