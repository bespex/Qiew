## What's new

- **“+” changes an existing comment**: on a block that has comments, “+” (key or button) no longer adds another one but opens its last open comment for changing. A further comment is still one keystroke away: Ctrl+Alt+M, or “+ Comment” in the card. The tooltip of the “+” says which it does.

Install: `sudo apt install marq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
