## What's new

- **The + key comments** (`--annotate`): point at a block and press `+`; the comment card opens with the cursor in the field, as with a click on the margin button.

## Fixed

- **Comments on single list items**: pointing at a bullet or a number, or at the gap between two items, used to offer one comment for the whole list. It now stays with the nearest item, so a single item can be commented, nested lists included.

Install: `sudo apt install marq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
