## What's new

- **Comment cards like Dirq's**: the "+" in the margin, the card a comment is written in and the comments in the card at the marks are now the same as in Dirq. The card stands out from the page (tinted in the comment's colour, a frame and a shadow) and has a heading with the type chips; its texts are in English like the rest of Marq.
- **Esc closes the window** when nothing else (the search, the outline, a card) takes it.

Install: `sudo apt install marq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
