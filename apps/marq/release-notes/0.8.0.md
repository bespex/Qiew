## What's new

- **Formulas**: LaTeX between `$…$` in the text, and as a block between `$$…$$` or in a ```` ```math ```` block, is set with KaTeX. A formula with an error shows its source in red, with KaTeX's message as tooltip; "$5 and $10" stays text. KaTeX is part of Marq, works offline and is only loaded for documents that have formulas.
- **HTML export**: formulas are exported as MathML, which browsers show themselves.

Install: `sudo apt install marq` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
