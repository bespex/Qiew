## What's new

- **Comments on the page**: started with `--annotate` (as CodeDeck does for the files of a project), Hyqe lets you comment on the elements of the page. Point at a paragraph, a button or a picture: a line marks it and a “+” appears beside it. Press “+” and write – for an AI assistant (`@ai`), yourself (`@me`) or others (`@you`). The comment goes into the file as `<!-- @ai: … -->` right before that element; on an element with comments, “+” opens its last open one for changing, Ctrl+Alt+M adds a further one.
- **Content first, structure on request**: Hyqe picks the block of text, the picture or the control under the pointer; Alt+↑ takes the card or section around it instead, Alt+↓ goes back.
- **The page stays as it is**: before anything is written, Hyqe parses the page as a browser does and checks that it looks the same with the comment – otherwise nothing is written. Only comment text changes, and the page keeps its state (no reload after your own comment).
- **Comments shown**: dots beside an element show its comments in the colour of their type; point at them for the text, click to tick off, change or remove one. F7 / Shift+F7 jump from comment to comment. Without `--annotate`, comments are only shown.

Install: `sudo apt install hyqe` (be spex package repository), the `.deb` or the AppImage below. The AppImage updates itself.
